How to connect your YouTube channel
Follow these steps to enable automatic video uploads. This uses YouTube's official Data API v3.
  • 1
    Create a Google Cloud Project Go to console.cloud.google.com → New Project → Name it "YouVideo.ai"
  • 2
    Enable YouTube Data API v3 APIs & Services → Enable APIs → Search "YouTube Data API v3" → Enable
  • 3
    Create OAuth 2.0 Credentials APIs & Services → Credentials → Create Credentials → OAuth Client ID → Web Application → Add your domain to Authorized redirect URIs
  • 4
    Get your Client ID & Secret Download the credentials JSON or copy the Client ID and Client Secret from the credentials page
  • 5
    Enter credentials below & connect Paste your credentials, click Connect, and authorize YouVideo.ai via Google's OAuth screen

Pre-Launch Checklist
  • 1
    Security: Move API keys to environment variablesNever expose Anthropic or YouTube API keys in frontend code. Use server-side API routes.
  • 2
    Rate limitingAdd per-user rate limits on pipeline endpoint to prevent abuse and control API costs.
  • 3
    Error monitoringSet up Sentry.io (free tier) to catch production errors before users report them.
  • 4
    Terms of Service & Privacy PolicyRequired before taking payments. Use Termly.io to auto-generate compliant docs.
  • 5
    Load testingUse k6 or Artillery to simulate 100 concurrent users. Fix bottlenecks before launch.
  • 6
    YouTube API quota managementDefault quota is 10,000 units/day. Video uploads cost 1,600 units. Apply for quota increase early.
  • 7
    Beta test with 10 real usersRun a free beta before charging. Collect feedback via Typeform. Fix top 5 issues first.
